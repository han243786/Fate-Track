# 简易八字解盘模型研究报告

## 研究背景

《三命通会》是明代万民英所撰的星命学典籍，它汇集了八字命理的重要理论，涵盖五行旺衰、十神格局、刑冲合会、大运流年等内容。随着人工智能与程序设计的发展，将这些命理知识结构化并构建可解释的模型成为可能。网上已有开源项目展示了这一方向，例如 Python 开发者社区提供的 **bazi** 排盘工具，具有清晰显示冲、合、刑等关系的能力，且附带《三命通会》等命理评判，被称为目前功能最强大的免费开源排盘工具【873583774210930†L44-L46】。

根据该项目的教程，八字强弱的判断依赖于日干在四季十二月份（月令）中的得令与失令、八字中其他干支对日干的生克合冲刑害关系、日干在整体八字中的位置以及五行的整体分布【873583774210930†L108-L121】。八字可分为偏强、偏弱和中和三种情况：日干得到大量同类五行生扶或受克少则偏强，日干生扶少或被异类克制多则偏弱，生扶与克制适中则为中和【873583774210930†L115-L119】。这些概念为模型构建提供了理论依据。

本项目旨在构建一个简易的八字解盘模型，使之能够：

1. 接受用户输入的四柱（年柱、月柱、日柱、时柱），或在未来通过日期自动排盘。
2. 自动计算五行分布、日主强弱、十神分布等核心指标，并引入月令旺相休囚权重和地支藏干，使日主强弱判断更加符合经典理论。
3. 基于完备的规则产生解盘报告，分析性格、事业、财富等方面的倾向，解释十神结构的现实含义，并给出调理建议。
4. 提供二进制模型序列化能力和一个友好的前端界面以便部署，包括命令行和简易网页接口。

## 模型设计

### 数据结构

模型输入为一个包含四个元素的列表，每个元素为一个 `(天干, 地支)` 元组，对应 **年柱、月柱、日柱、时柱**。模型计算的主要指标包括：

1. **五行计数**：统计八个字中木、火、土、金、水各出现的次数。
2. **日主强弱**：根据日主五行出现的次数简单划分为“偏旺”“偏弱”或“中和”，参考《三命通会》强调的旺衰原则【873583774210930†L108-L121】。
3. **十神分布**：针对日干，与其他三柱的天干比较，判定五种简化的十神（比肩、印星、食伤、财星、官杀）出现次数，用于描述人与环境的关系。
4. **解盘叙述**：组合上述指标生成文字报告，除阐述五行强弱、取补建议以及十神结构对命主行为的影响外，还从性格、职业、财务、情感四个维度给出具体分析，并生成大运流年简述。

### 规则与算法

1. **五行映射**：为每个天干、地支关联其主五行。初步采用常见的映射表，如甲、乙对应木，丙、丁对应火，戊、己对应土，庚、辛对应金，壬、癸对应水；子属水、丑属土、寅卯属木、巳午属火、申酉属金、辰戌丑未属土、亥属水等。

2. **日主强弱判定（改进）**：

   * **元素交互权重**：对八字中每一个天干（包括地支藏干）按其与日主的生克关系赋予权值。同元素加 1 分，生助日主加 0.8 分，日主克制他人减 0.6 分，日主所生之物减 0.6 分，克制日主者减 1 分。
   * **月令旺衰加权**：根据旺、相、休、囚、死与余气五种状态分别赋予权重（1.2/1.0/0.8/0.5/0.3/0.8），用以修正日主得分，体现季节对五行强弱的影响【113397001662516†L17-L59】。
   * **强弱划分**：加权后的得分≥3.0 视为“偏旺”，≤0 视为“偏弱”，介于其间为“中和”。这种方法兼顾了季节与生克制化，较单纯计数法更贴近传统命理【113397001662516†L17-L59】。

3. **十神分类（升级）**：完整的十神体系区分五对正偏关系。判断方法为：

   - **比肩/劫财**：若其他干与日主同五行且同阴阳为比肩，阴阳不同为劫财，代表伙伴与竞争关系。
   - **正印/偏印**：若其他干生助日主，且阴阳相同为正印，阴阳不同为偏印，象征学习、资质与贵人。
   - **食神/伤官**：若日主生其他干，阴阳相同为食神，阴阳不同为伤官，代表表达与创造力。
   - **正财/偏财**：若日主克制其他干，阴阳相同为正财，阴阳不同为偏财，表示财富获取与资源调配。
   - **正官/七杀**：若其他干克制日主，阴阳相同为正官，阴阳不同为七杀，象征权力、责任与压力。

   这种分类将十神从五类细分为十类，使命局解读更加精细。

4. **报告生成**：根据计算结果输出自然语言：包括日主所属五行与阴阳属性、旺衰状态、五行分布、十神分布，并解释各类十神在性格、事业、财运等方面的象征意义，提出补足或泄泻的具体建议，并强调该分析仅供参考。

### 模型实现

模型使用 Python 编写，核心类 `BaZiModel` 位于 `bazi_model.py`。升级版引入了隐藏干分析和季节加权，主要接口包括：

* `analyze(pillars) -> BaZiReport`：接收四柱列表，返回包含五行统计、日主强弱、十神分布和叙述的 `BaZiReport` 实例。
* `save_binary(filepath)` / `load_binary(filepath)`：使用 `pickle` 将模型序列化为二进制文件或从二进制文件反序列化，便于部署或网络传输。

`BaZiReport` 数据类包含分析结果及用于展示的文字报告。它提供五行计数、日主强弱、十神分布、月令权重、日主阴阳属性以及完整的叙述。升级后的模型在分析十神时会遍历地支藏干，并将其与日干比较，以获得更细致的结构信息。

### 前端接口

为了便于用户交互，本项目提供两种前端方式：

1. **命令行界面 (CLI)**：脚本 `app.py` 接受 `--pillars` 参数（四个两字组合，如 `甲子 丙申 壬午 庚辰`），输出详细的解盘报告。

2. **Streamlit Web 应用**：通过运行 `streamlit run app.py --web` 可启动网页界面，用户可在浏览器输入四柱并即时查看分析结果。这种方式利用了 Streamlit 的轻量级 Web 界面能力，无需前端开发经验即可部署。

### 模型验证

为确保模型逻辑正确，我们对多组代表性八字进行了测试，包括五行均衡、偏旺、偏弱等情况。模型能正确统计五行、判断日主强弱，并输出合理的调理建议。由于采用的是规则系统而非神秘算法，验证重点在于规则正确性和数值边界处理。后续可引入更多命例对比传统解盘结果进行迭代调整。

## 已实现的扩展与未来工作

在进行深度研究与实现后，模型已经完成以下关键扩展：

1. **引入月令旺衰加权**：根据旺相休囚死表为日主得分赋予不同权重，体现季节影响。
2. **地支藏干分析**：模型会遍历每个地支的藏干，并将其纳入十神和强弱计算，使分析更细致。
3. **十神全分类**：支持比肩、劫财、食神、伤官、正财、偏财、正官、七杀、正印、偏印十类角色，输出更加专业的结构分析。
4. **报告解释性增强**：在报告中增加日主阴阳属性说明、十神象征意义解析与具体调理建议。
5. **多维度解读**：报告新增性格、职业、财务、情感分析及大运流年概述，使解盘更加全面。
6. **性别选项**：前端界面增加性别下拉菜单，模型在情感与大运解读中可参考性别差异。

未来仍有以下工作值得探索：

1. **排盘自动化**：集成公历转农历、真太阳时校正等功能，以输入出生日期直接生成四柱。
2. **大运流年分析**：加入大运和流年计算，生成阶段性运势报告。
3. **可视化输出**：开发 PDF/HTML 模板和图表展示，提升报告的视觉效果和互动性。
