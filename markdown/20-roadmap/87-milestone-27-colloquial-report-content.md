# M27: Zero-Baseline Colloquial Chart Report Content

## 1. 目标

将报告文案从专业术语堆叠升级为零基础用户能读懂的命盘说明书。保持后端硬编码模板架构，不引入 AI/LLM。每个章节遵循统一的阅读结构：这一章看什么 → 你的结果 → 换成白话怎么理解 → 应该怎么看、不应该怎么看。

## 2. 依赖

- M24 chart-report 后端报告框架。
- M26 报告页门户渲染。

## 3. 范围

| Work Package | 内容 |
| --- | --- |
| M27-WP1 | 免责声明升级：告诉用户"报告应该怎么读" |
| M27-WP2 | 十天干各一段完整生活化比喻（甲→大树，乙→花草，丙→太阳，丁→灯火…） |
| M27-WP3 | 五行分布：每个元素输出等级 + 白话解释，区分缺/偏弱/中和/偏强 |
| M27-WP4 | 十神关系：十个十神各一段白话说明 |
| M27-WP5 | 地支藏干："隐藏按钮"比喻 + 说明不需死记 |
| M27-WP6 | 日主强弱：得令/得地/得势 白话解释 + 五个等级生活化描述 |
| M27-WP7 | 格局初判：七种格局各一段白话说明，强调"主题"非"等级" |
| M27-WP8 | 用神参考："调节方向"非"命令"，附带五行白话 |
| M27-WP9 | 大运走势："阶段气候"比喻，简化天文依赖 |
| M27-WP10 | 专业词替换规则：统一语气（你可以理解为…换成白话说…这不是说…） |

## 4. 非目标

- 不引入 AI/LLM 生成
- 不修改 API 接口
- 不新增能力
- 不修改前端渲染

## 5. 能力状态

无变化。`chart-report` 保持 restricted。
