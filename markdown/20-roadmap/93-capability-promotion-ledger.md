## 3. 晋级流程

1. 在对应里程碑中列出能力。
2. 实现 Rust/API/test 证据。
3. 更新 `/api/capabilities` 或等价能力声明。
4. 更新本台账 Evidence。
5. 更新前端文案或 UI 状态。
6. 运行完整门禁。
7. 在 closeout 中记录晋级结果。

## 4. 降级流程

如果 supported 能力证据不再成立，必须：

- 立即把 capability 状态降为 restricted/planned。
- 记录触发原因和影响用户。
- 保留失败样例。
- 更新 README、模块树、前端文案。
- 关闭前不得继续宣称 supported。
