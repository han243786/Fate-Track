# M21: Deep Analysis — 三命通会/子平法蒸馏

## 1. 目标

在现有结构化分析之上，增加基于三命通会和子平法原则的深层结构化推理。全部规则硬编码（无 AI 生成），输出为固定模板卡片。

## 2. 依赖

- M4 analysis-snapshot 已有五行/十神/藏干指标。
- M11 天文引擎可提供节气时刻。

## 3. 范围

| Work Package | 内容 |
| --- | --- |
| M21-WP1 | 日主强弱判定：得令/得地/得势三维度 |
| M21-WP2 | 格局初判：正官格/七杀格/财格/印格/食伤格/建禄格等 |
| M21-WP3 | 用神建议：基于强弱+格局的喜忌提示（标注"传统参考，非确定性建议"） |
| M21-WP4 | 扩展分析卡片：强弱分析卡、格局分析卡、用神参考卡 |
| M21-WP5 | 全部规则来自三命通会/子平法原则的硬编码蒸馏 |

## 4. 非目标

- 不生成自由文本
- 不提供医疗/法律/金融/关系确定性断言
- 不声称预测准确性
- 不用 AI/LLM

## 5. 能力状态

`analysis-snapshot` 保持 supported，扩展卡片内容。
