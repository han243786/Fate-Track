# M50 Topic Report Advice Cohesion

Status: closed by LOOP-118. Closeout: `139-milestone-50-closeout.md`.

## 1. 目标

M50 承接 M47 情感报告黄金样例、M48 三专项计数字段叙事基线和 M49 年度/大运流年叙事基线。M49 后，金钱、家庭、事业三份专项报告已经不再露出清单证据，但正文仍有说明书口吻，例如 `日常读法`、`日常看`、`这些牵动提醒您`、`这份报告适合当作` 和多处重复现实提醒。

本轮把金钱、家庭、事业三专项的开场、解释章、年度引动和结论推向“专项解盘”形态：先给总断，再解释关键结构，再落到年度节奏和结论建议。情感报告继续作为黄金样例保持不动，主盘报告不在本轮扩大重写。

## 2. 叙事基线

三专项正文必须保持：

- 开场使用 `总断`，直接进入金钱/家庭/事业主题的结构判断。
- 第二章不再叫 `日常读法`，分别改为 `资源入口`、`互动位置`、`事业用力方式`。
- 结论章使用专题关键词收束，例如 `您的金钱关键词`、`您的家庭关键词`、`您的事业关键词`。
- 现实提醒集中在报告开头免责声明；正文内只保留必要的结构边界和资料完整性说明，不反复打断读感。
- 年度引动仍使用显式年份，例如 `2026年`，不得回退为 `指定年份`、`这一年` 或泛化年份。
- 不得回退到清单、台账、后端变量、计数字段、内部英文、score、0-100 分、现实收益/亲属事件/岗位结果断言。
