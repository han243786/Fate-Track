# M46 Report Narrative List Cleanup Gate

Status: closed by LOOP-114. Closeout: `131-milestone-46-closeout.md`.

## 1. 目标

M46 承接五份真实报告的轮回打磨 goal：继续从 `target/report-polish-samples/` 的真实生成结果出发，把仍像清单、统计表或调试说明的正文改成更像命理师讲解的叙事。

本轮重点清理：

- 主盘年度引动里的 `盘中能看到的关键牵动是`、`日主「庚」：...` 这类锚点清单。
- 四专项大运流年里的 `盘中可用的时间线索有十条，其中五条...`、`读这一段时`、`2026年重点看的牵动`。
- 情感报告里的 `出现 4 处`、`正财 0 处`、`食伤出现 1 处` 这类数字台账。
- 金钱、家庭、事业报告里的 `这张命盘里的...信号为`、`结构上被点亮`、`从现有四柱看` 和双重模板冒号。

本轮只改可见正文和质量门禁，不改变 API route、DTO 顶层结构、capability 状态或 raw `GET /api/luck/cycles` 语义。

## 2. 文案门禁

五份真实 assembled report 不得出现：

- `盘中可用的时间线索`
- `重点看的牵动`
- `读这一段时`
- `在盘中有`
- `关键牵动是`
- `盘中能看到的关键牵动`
- `这张命盘里的`
- `食伤出现`、`比劫出现`、`印星出现`
- `出现 0 处`、`出现 1 处`、`出现 2 处`、`出现 3 处`、`出现 4 处`
- `正财 0 处`、`偏财 1 处`
- `结构上被点亮`
- `从现有四柱看`
- `的重心更偏向`
- M41-M45 已登记的内部英文、后端变量、系统/算法/评分、裸露合冲刑害和 fixed-opener 回归项

## 3. 验收

- 重新生成 `main.txt`、`relationship.txt`、`wealth.txt`、`family.txt`、`career.txt`。
- 五份样本 M46 禁用词命中为 0。
- 五份样本 ASCII word 命中为 0。
- 主盘年度引动使用“先看天干 / 再看五行 / 地支关系上”等阅读顺序，不再显示锚点清单。
- 四专项大运流年使用 `2026年的主要牵动如下` 和具体信号名，不再显示“十条/五条”统计说明。
- 情感与其他专项计数表达统一为“有一处落点 / 不作主线”等自然中文。
- `cargo test report -- --nocapture`、`cargo test topic_report -- --nocapture` 通过。
- 治理脚手架通过。
