# 命轨 Fate Track

命轨是一款本地运行的四柱八字排盘与命理报告工具。

命轨会依据您输入的出生日期、时间和性别排出命盘，并呈现主盘报告、情感、金钱、家庭、事业四类专项报告，以及大运和所选年份的流年引动说明。

> 命理报告属于传统文化视角下的结构化解读，适合用于自我观察、关系复盘和节奏参考，不应替代医疗、法律、投资、婚姻或职业决策。

## 安装与启动

1. 下载 `Fate-Track-Windows-x64.zip`
2. 解压到您方便保存的位置
3. 打开解压后的文件夹
4. 双击 `minggui-desktop.exe`

首次运行时，Windows 可能会提示“Windows 已保护你的电脑”。这是因为当前预览版尚未做代码签名。确认来源为本仓库下载后，可以选择“更多信息”，再选择“仍要运行”。

命轨是本地桌面应用，不需要安装 Node、Python 或数据库。

## 使用说明

### 1. 起盘

打开应用后，在主界面输入：

- 出生日期
- 出生时间
- 时区
- 性别

如果出生时间不确定，可以使用未知时辰。命轨会保留这份不确定性，不会伪造一个确定时柱。

### 2. 查看主盘

起盘后可以查看：

- 年柱、月柱、日柱、时柱
- 日主
- 十神关系
- 五行分布
- 格局和用神提示
- 大运走势
- 所选年份的年度引动

主盘报告会尽量用自然语言解释命理结构，同时保留必要的专业词汇。

### 3. 查看四类专项报告

主界面左下方提供四个专项入口：

- 情感
- 金钱
- 家庭
- 事业

点击后可以进入对应专项报告。每份报告会从原局结构、大运背景和所选年份引动三个层面进行解读。

### 4. 选择年份

您可以选择某一年查看当年的流年信息。

例如选择 `2026`，报告会围绕 2026 年与命盘、大运之间的关系展开说明，而不是只给出干支符号。

### 5. 保存与分享

当前版本支持本地案例和脱敏分享预览。请注意：

- 案例数据是本地易失存储，不等同于长期云端保存
- 分享预览会尽量隐藏私密信息
- 当前版本没有账号、云同步或跨设备同步

## 当前能做什么

命轨当前支持：

- 公历日期起盘
- 1901 年至 2100 年范围内的日期计算
- 四柱八字排盘
- 日主、十神、五行、格局、用神方向分析
- 大运排盘
- 所选年份流年引动
- 主盘完整报告
- 情感、金钱、家庭、事业四类专项报告
- 本地案例管理
- 脱敏分享预览
- 术语解释
- 金、木、水、火、土五套界面主题

## 当前不做什么

当前版本暂不支持：

- 农历日期直接输入
- 真太阳时
- IANA 历史时区
- 账号系统
- 云端同步
- 自动更新
- 在线智能解读
- 流月、流日、择日、每日运势
- 安装包格式，如 `.msi`、`.dmg`、`.deb`
- 公开代码签名和 macOS 公证

## 常见问题

### 为什么打开时会有安全提示？

因为当前 Windows 预览版没有代码签名。只要文件来自本仓库发布产物，并且 SHA256 校验一致，就说明它与本次构建产物一致。

### 为什么不能直接输入农历生日？

当前版本的计算入口是公历日期。农历输入涉及另一层转换边界，后续需要单独验证后再开放。

### 为什么报告里不会给绝对结论？

命轨的定位是结构化命理解释，不做绝对断事。报告会说明倾向、牵动、节奏和需要留意的关系，而不是替用户做决定。

### 换一个出生时间后，之前的报告还有效吗？

不一定。出生时间会影响时柱和部分结构判断。重新起盘后，请以新的报告为准。

### 每个人的起运年龄一样吗？

不一样。起运年龄会受到出生时间、节气位置、性别和顺逆规则影响。命轨会按当前规则计算大运起点。
