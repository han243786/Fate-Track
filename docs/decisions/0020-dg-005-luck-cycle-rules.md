# ADR 0020: DG-005 Luck Cycle Rules

## Status

Accepted. Closes DG-005.

## Decision

大运（Luck Cycles）采用以下规则：

### 顺逆判定

| 年干 | 性别 | 方向 |
|------|------|------|
| 甲丙戊庚壬（阳年） | 男 | 顺行 |
| 甲丙戊庚壬（阳年） | 女 | 逆行 |
| 乙丁己辛癸（阴年） | 男 | 逆行 |
| 乙丁己辛癸（阴年） | 女 | 顺行 |

### 起运年龄

起运年龄 = 出生日到下一个（顺行）或上一个（逆行）节气的天数 ÷ 3。

- 顺行：从出生日到下一个节（Jie，立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）
- 逆行：从出生日到上一个节
- 每天 = 0.333... 岁（3天折1岁）
- 结果保留整数（不足1岁按1岁计，上限10岁）
- 出生日恰逢节气当天：起运年龄 = 0（即出生即起运）

### 大运排法

- 第一运始于月柱，每运10年
- 顺行：月柱干支各进一位 → 下一运
- 逆行：月柱干支各退一位 → 下一运
- 大运共排8运（覆盖80年，与人生预期一致）

### 边界

- M13 只排大运，不排流年/流月。
- 不提供大运分析或确定性断言。
- 时辰未知时仍可排大运（仅使用年/月/日柱）。

## Consequences

- DG-005 关闭，luck-cycles 可晋级为 supported。
- `GET /api/luck/cycles` 路由实现。
- `/api/capabilities` 更新 luck-cycles 为 supported。
- 新增 `backend/src/domain/luck.rs`。
- 黄金样例覆盖阴阳年干×男女×顺逆全部组合。

## Evidence

- ADR 0020 记录决策。
- `backend/src/domain/luck.rs` 实现大运计算。
- `backend/src/api/luck.rs` 提供 API 路由。
- Rust 测试覆盖顺逆判定和起运年龄边界。
