# 命轨当前产品边界

本文件记录当前可交付产品边界。它面向用户与发布检查，不是新功能规划。

## 产品定位

命轨是本地运行的四柱八字排盘与命理报告工具。当前版本只做结构化排盘、命理报告、专项报告、大运与指定年份引动解释，以及围绕这些能力的本地使用体验优化。

所有报告均为传统文化视角下的固定规则与固定模板解释，不接入在线 AI，不给医疗、法律、投资、婚姻或职业决策承诺。

## 用户可见功能

当前产品对用户开放以下功能：

- 公历日期起盘，日期范围为 1901 年至 2100 年。
- 四柱命盘展示：年柱、月柱、日柱、时柱、日主、十神、五行、藏干、格局与用神方向。
- 主盘完整报告。
- 情感、金钱、家庭、事业四类专项报告。
- 大运排盘与当前大运说明。
- 显式选择年份后的年度引动说明。
- 本地案例管理与本地偏好。
- 脱敏分享预览。
- 术语解释。
- 金、木、水、火、土五套视觉主题；视觉主题只改变呈现风格，不改变计算和报告结论。

## 受限能力

以下能力可以出现在产品中，但必须保持受限口径：

- 案例、设置和分享预览均为本地能力，不承诺云端保存、跨设备同步或长期托管。
- 主盘报告和四类专项报告均为 restricted 能力；可见正文不得暴露 `score_internal`、内部字段、调试口吻或工程实现说明。
- 大运和年度引动只解释显式传入的年份与当前大运关系，不开放流月、流日、择日、每日运势或事件预测系统。
- 四类专项报告只覆盖情感、金钱、家庭、事业，不扩展健康、子女、学业、诉讼、迁移等新专题。
- 四类专项报告对应 capability id 为 `relationship-report`、`wealth-report`、`family-report`、`career-report`。
- raw `GET /api/luck/cycles` 保持纯计算输出，不加入报告正文、评分、年度解释或专题叠加。

## 当前不支持

当前产品明确不支持：

- 农历日期直接输入。
- 真太阳时。
- IANA 历史时区。
- 账号系统。
- 云同步。
- 自动更新。
- 在线 AI 解读。
- 流月、流日、择日、每日运势。
- 医疗、法律、投资、婚姻、职业结果承诺。
- `.msi`、`.dmg`、`.deb` 等安装包格式。
- 公开代码签名和 macOS 公证。

## 能力矩阵

后端 `/api/capabilities` 当前真源目录为 24 项：10 项 supported，14 项 restricted，0 项 planned。

用户文档与发布说明不得宣称 planned 功能已经存在；任何新增功能必须先进入里程碑、能力矩阵、质量门禁和 closeout。

## 发布门禁

当前产品边界由以下证据共同守住：

- `backend/src/api/capabilities.rs`
- `frontend/tests/workspace-markup.test.mjs`
- `tools/check-release-candidate.ps1`
- `tools/check-project.ps1`
- `docs/release/current-product-boundary.md`

任何用户可见功能扩展、报告专题扩展、时间解释扩展或分享/存储能力扩展，都不得绕过以上文件。
